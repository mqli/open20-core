# 需求：装备管理（Equipment）

## 需求描述

管理武器、护甲、盾牌、冒险装备、金币。

装备影响AC计算、攻击加值、技能检查（工具熟练项）。

## 验收标准

- [ ] 武器列表：名称、伤害、属性、精通属性、装备/卸下
- [ ] 护甲列表：名称、AC加值、Dex奖励、装备/卸下（影响AC）
- [ ] 盾牌：单独管理，装备后AC+2
- [ ] 物品列表：名称、数量、重量（可选规则）
- [ ] 金币管理：CP/SP/EP/GP/PP，支持 +/- 修改
- [ ] 装备/卸下武器时，游戏模式攻击列表自动更新
- [ ] 装备/卸下护甲时，AC自动重算
- [ ] 重甲力量不足时提示（移动力减半，不阻止装备）

## 数据模型

引用 `../../spec/data-model.md` 中的以下结构：

- `Equipment` — 装备基础结构
  - `Weapon` — 武器（含伤害、属性、精通属性）
  - `Armor` — 护甲（含AC加值、Dex奖励、力量需求）
  - `Item` — 通用物品（含名称、数量、重量）
- `Currency` — 金币（CP/SP/EP/GP/PP）
- `Character.equipment` — 角色装备列表
- `Character.currency` — 角色金币

## 边界情况

- 同时装备多把武器时，攻击列表需显示所有已装备武器的攻击动作
- 护甲和盾牌同时装备时，AC计算公式：`baseAC + armorBonus + shieldBonus + dexBonus（受护甲类型限制）`
- 变体规则「无甲AC」或「非受训护甲」需特殊处理（MVP可不支持，预留接口）
- 物品重量为0或负数时，按0处理
- 金币数量为负数时，阻止操作并提示
