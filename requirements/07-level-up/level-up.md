# 需求：等级提升（Level Up）

## 需求描述

角色升级时自动获得新特性、HP增量、新法术（施法者）、ASI或专长（特定等级）。

MVP仅支持单职业升级。

## 验收标准

- [ ] 增加角色等级（单次或多次）
- [ ] 自动计算HP增量（ceil(hitDie/2) + ConMod）
- [ ] 显示新等级获得的所有特性（来自职业特性列表）
- [ ] 4/8/12/16级弹出ASI/Feat选择（属性+2 或 属性+1+专长+1）
- [ ] 19级弹出Epic Boon选择（专长大类）
- [ ] 施法者在特定等级获得新法术（自动加入knownSpells）
- [ ] 升级后自动更新：熟练加值、HP最大值、法术位总数
- [ ] 支持HP增量选择：固定值 或 掷骰

## 数据模型

引用 `../../spec/data-model.md` 中的以下结构：

- `Character.classes[].level` — 职业等级
- `Character.hitPoints.max` — 生命值上限
- `Character.resources` — 新增资源（升级时可能获得新资源）
- 升级时写入 `Character.updatedAt`

## 边界情况

- 多次连续升级时，需按等级顺序依次应用每个等级的特性（不能跳过中间等级）
- HP增量掷骰结果需记录，以便导出/导入时保持一致
- ASI/Feat选择冲突时（如已选过同名专长），需提示用户
- 跨多职业升级（MVP不支持，需明确提示不支持多职业）
- 升级前若角色数据不合法（如缺少必要字段），需阻止升级并提示
