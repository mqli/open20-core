# 需求：专长选择 (Feats Selection)

## 1. 需求描述

玩家从75个2024版专长中选择，按4个类别分组显示。专长在特定等级获得（通常为4/8/12/16/19级），玩家可选择获得专长或属性点提升（ASI）。

**2024规则变更：**
- 专长数量从2024 PHB的75个（相比2014大幅增加）
- 专长分为4个类别：Origin / General / Fighting Style / Epic Boon
- Origin Feat由背景授予，不需在此选择（但需显示）
- Epic Boon仅19级可选（MVP提示"等级不足"）

**重要说明：**
- 每4级获得一个专长或属性点提升（二选一）
- 专长前提条件必须校验（属性/等级/子职业/种族）
- 已选专长影响属性加值、技能、攻击加成等

---

## 2. 验收标准

### 2.1 专长列表显示
- [ ] 专长按类别分组：Origin / General / Fighting Style / Epic Boon
- [ ] 每个类别显示专长数量（如"General (58)"）
- [ ] 显示每个专长的：
  - 名称（中英文）
  - 前提条件（如有）
  - 描述摘要（前50字 + "展开"）
  - 图标/插图（如有）
- [ ] 支持搜索：按名称、描述、前提条件搜索
- [ ] 支持筛选：按类别、前提条件、是否已选筛选

### 2.2 专长详情查看
- [ ] 点击专长卡片展开详情
- [ ] 详情包含：
  - 完整描述
  - 前提条件（红色高亮未满足项）
  - 来源（背景/PHB/其他）
  - 影响的属性/技能/攻击加值
- [ ] 显示"已选择"标记（如已选）
- [ ] 显示"可获得等级"标记（如尚未达到）

### 2.3 专长选择交互
- [ ] 点击"选择"按钮选择专长
- [ ] 选择时校验前提条件：
  - 属性要求（如力量13+）
  - 等级要求（如19级才能选Epic Boon）
  - 子职业要求（如特定子职业专有的专长）
  - 种族要求（如特定种族专有的专长）
- [ ] 前提条件不满足时禁用"选择"按钮，显示提示
- [ ] 每个可获得专长等级只能选一个专长（或ASI）
- [ ] 选择后显示确认弹窗："确认选择 [专长名]？（将消耗第X级的专长选择机会）"

### 2.4 专长与ASI二选一
- [ ] 在可获得专长的等级（4/8/12/16/19），显示选择界面：
  - 选项A：选择一个专长
  - 选项B：属性点提升（两项属性+1，或一项属性+2）
- [ ] 未做选择时，显示"待选择"标记
- [ ] 支持更换选择（在升级时未确认前可更换）
- [ ] 确认后写入 `Character.feats` 或 `Character.abilityScores.base`（ASI）

### 2.5 特殊类别处理
- [ ] **Origin Feat**：
  - 由背景自动授予，显示但不可选
  - 显示来源背景名称
  - 计入已选专长列表
- [ ] **Epic Boon**：
  - 仅19级可选
  - MVP阶段：未达19级时显示"等级不足"，禁用选择
  - 完整版：19级时解锁选择
- [ ] **Fighting Style**：
  - 仅特定职业可选手（Fighter/Ranger/Paladin等）
  - 校验职业前提条件

### 2.6 自定义专长（P1功能，MVP预留入口）
- [ ] MVP阶段：显示"自定义专长"按钮（置灰，点击提示"功能开发中"）
- [ ] 完整版：支持自由文本输入专长名称和效果
- [ ] 自定义专长标记为"自定义"，与其他专长区分

### 2.7 数据持久化与显示
- [ ] 已选专长列表写入 `Character.feats`
- [ ] 专长影响的属性加值自动写入 `Character.abilityScores.featBonuses`
- [ ] 已选专长在角色表中可见（专长标签页）
- [ ] 支持取消选择（在升级时未确认前可取消）
- [ ] 已确认的专长不可取消（除非使用"重新分配"功能）

## 3. 数据模型

引用 `spec/data-model.md` 中的定义：

```javascript
Character.feats = [
  "Savage Attacker",      // 专长名称（英文key）
  "Tough",
  "Alert"
]

// 专长详情存储在独立集合中（便于查询前提条件等）
Feat = {
  "id": "savage-attacker",
  "name": {
    "en": "Savage Attacker",
    "zh": "野蛮攻击者"
  },
  "category": "General",  // Origin / General / Fighting Style / Epic Boon
  "prerequisites": {
    "ability": null,      // { "Strength": 13 } 或 null
    "level": null,        // 19（Epic Boon）或 null
    "subclass": null,     // 子类名或 null
    "race": null          // 种族名或 null
  },
  "description": {
    "en": "When you hit a creature with a weapon...",
    "zh": "当你用武器击中生物时..."
  },
  "effects": {
    "abilityBonuses": null,  // { "Strength": 1 } 或 null
    "skillProficiencies": null,
    "other": "Advantage on first attack roll each turn"
  },
  "source": "PHB 2024"
}

// 自动计算的专长加值（不手动输入）
Character.abilityScores.featBonuses = {
  "Strength": 1,          // 假设选了+1力量的专长
  "Constitution": 0,
  "Dexterity": 0,
  "Intelligence": 0,
  "Wisdom": 0,
  "Charisma": 0
}
```

**专长选择记录（用于追踪哪个等级选了什么）：**

```javascript
Character.featSelections = [
  {
    "level": 4,
    "type": "feat",           // "feat" 或 "asi"
    "value": "Savage Attacker"
  },
  {
    "level": 8,
    "type": "asi",
    "value": { "Strength": +2 }
  }
]
```

## 4. 边界情况

### 4.1 前提条件校验
- **属性变化**：如果后期属性变化导致不满足专长前提，不撤销已选专长（2024规则）
- **多前提条件**：需同时满足所有前提条件（如"力量13+ 且 战士职业"）
- **可选前提**：某些专长有多个可选前提（如"力量13+ 或 敏捷13+"），满足任一即可

### 4.2 专长冲突
- **重复选择**：大部分专长不能重复选择（除非专长描述说明可重复）
- **效果叠加**：同类加值不叠加（如选两个+1力量的专长，只加一次）
- **特异性规则**：某些专长明确说明与特定特性冲突（需手动标注）

### 4.3 数据兼容性
- **2014专长**：检测 `Character.version === "2014"`，显示2014专长列表
- **自定义专长**：自由文本输入，不做前提条件校验
- **导入角色**：从D&D Beyond导入时，保留原始专长选择

### 4.4 UI交互
- **专长数量**：75个专长一次加载可能卡顿，需分页或虚拟滚动
- **搜索性能**：中文/英文搜索需建立索引（前端过滤可能慢）
- **触屏设备**：专长详情展开/收起需支持点击（不只hover）

### 4.5 等级变化
- **升级时**：自动检测到新等级可获得专长，提示"第X级可获得新专长/ASI"
- **降级时**（如管理员调整等级）：已选的高等级专长保留但标记为"未激活"
- **Multi-class**：多职业时专长按总等级计算（如Fighter 5 / Wizard 3，8级时可获得专长）

### 4.6 并发与状态
- **中途退出**：已选择的专长暂存到LocalStorage
- **恢复状态**：重新进入时恢复上次选择状态
- **多设备冲突**：同一角色在不同设备编辑时，以最后保存为准
